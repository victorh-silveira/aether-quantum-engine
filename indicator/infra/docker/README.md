# Infraestrutura do indicador

O unico Compose esta em `../../../infra/docker/docker-compose.yml`. Na raiz, `make docker-up` sobe indicador, motor/ML, TimescaleDB, Prometheus e Grafana. `make docker-smoke` valida os endpoints; `make docker-logs DOCKER_SERVICE=aether-market-signal-indicator` mostra os logs do servico publico. O Prometheus le `aether-market-signal-indicator:9101` pela rede interna. O diretorio `indicator/data/indicator-models` e montado somente para leitura no servico; `make app-train` treina primeiro esse indicador e depois TCN/meta/loss. Banco e Grafana usam as mesmas instancias do motor.
