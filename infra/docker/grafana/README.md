# Grafana Dashboards e Provisionamento

Diretorio de configuracao e definicoes declarativas do servico Grafana na stack unificada Docker Compose.

## Estrutura

- **`provisioning/dashboards/`**: Modelos de paineis analiticos (Aether Business Dashboard, telemetria de ordens e liquidações).
- **`provisioning/datasources/`**: Conexao declarativa automatica com o Prometheus (`localhost:9090`).
